 Verification Review Guideline 
Teams should use the following guideline when conducting reviews of test cases and verification procedure, and when entering verification evidence. The RMP column aligns with the criteria.  
Item 
 Evaluation Criteria 
 RMP Section 
 
 Confirm the safety checklist is completed. 
 
 
 
 
 
 
 
 
 
 Confirm the test report reference and other evidence has been entered into the verification matrix. 
 
 
 
 Confirm the verification procedure completely implement the verification case(s) they trace to. 
 
 Confirm the test environment conditions are documented and that they are sufficient and necessary for the test cases. 
 
 Confirm the initial test environment conditions are set for the test case they execute. 
 
 Confirm the verification procedure includes any necessary additional step-by-step instructions for how each test case is set up and executed in the test environment. 
 
 
 
 Confirm the test case is feasible at the system level to independently test each unique system state and/or condition. 
 
 
 
 Confirm, if feasible, the test case tests out of range or unexpected inputs. 
 
 
 
 Confirm there are adequate checks in the verification procedure if not listed in the test cases to show the initial conditions setup is correct. 
 
 Confirm the verification procedure includes steps for performing test data logging, if needed.
